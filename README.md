# Calculator Using Functions and Control Structures

## Project Description
This is a simple menu-driven calculator written in C. It performs addition, subtraction, multiplication, and division.

## Features
- Performs all four basic arithmetic operations.
- Accepts multiple numbers.
- Supports decimal numbers.
- Uses separate user-defined functions for each operation.
- Uses `switch`, `for` loop, and `if` statements.
- Checks invalid choices and division by zero.

## Files
- `main.c` - Complete C source code.
- `sample_output.txt` - Example program output.
- `.gitignore` - Files to ignore in Git.

## How to Run
1. Open `main.c` in a C compiler such as GCC, Code::Blocks, or an online C compiler.
2. Compile and run the program.
3. Select an operation from the menu.
4. Enter how many numbers you want to calculate.
5. Enter the numbers separated by spaces or by pressing Enter.

## Compile Using GCC
```bash
gcc main.c -o calculator
./calculator
```

On Windows, run:
```bash
calculator.exe
```
